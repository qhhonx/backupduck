# Mac 文件夹备份

除了系统图库，Mac 还可以备份电脑、外置硬盘或 SD 卡文件夹里的照片和视频，包含子文件夹。iPhone 目前仅支持系统图库。

## 开始备份

1. 打开 **文件夹 → 添加文件夹**，选择要备份的位置。
2. 选择是否备份已有文件，以及是否开启自动备份。
3. 配对接收端后，照片和视频会加入传输队列。**查看文件**可以浏览文件、修改时间和接收状态。

**备份现有文件**：备份当前还没有备份的文件，并重试失败项。同一来源、同一接收端下，已排队或已接收且未变化的文件会跳过。换接收端或通过另一个来源添加相同文件，可能会另备一份。

**自动备份**：持续发现并备份新增和修改的文件。关闭后不再添加新任务，已经排队的文件继续传输。未选择备份已有文件时，首次扫描只记录现状，之后新增或修改的文件才会加入备份。

**停止本次备份**：停止手动备份继续准备文件，已排队的文件仍会传输。要暂停所有来源和传输，请使用全局暂停。

## 哪些文件会备份

支持 JPEG、HEIC/HEIF、PNG、GIF、WebP、TIFF、MOV、MP4 和 M4V。接收端也可能有格式限制。暂不支持 RAW 和普通文档；隐藏文件和符号链接不会扫描。

导出的实况照片需要照片与 MOV 同名，并保留匹配的 Apple 配对标识，才能作为一张实况备份。只有同名、不含配对标识的文件会分别处理。文件夹结构不会自动变成 Google 相册中的相册。

## 选择备份范围

每个文件夹可以单独设置 **备份规则**。规则匹配该文件夹内的相对路径，每行一条，区分大小写。

- **包含（白名单）**：只备份符合这些规则的照片和视频。留空表示包含所有支持的格式。
- **排除（黑名单）**：跳过符合这些规则的文件。留空表示不额外排除；同时符合包含和排除时，排除优先。

例如，包含 `旅行/**` 表示只备份“旅行”文件夹下的媒体；排除 `缓存/**` 表示跳过“缓存”文件夹。`**/*.jpg` 匹配各层级的小写 `.jpg` 文件；`**/*.{jpg,JPG}` 可以同时匹配这两种扩展名。

`*` 匹配一层内的字符，`**` 可跨越子文件夹，`?` 匹配单个字符。排除整个目录请写 `目录/**`，只写末尾 `/` 无效。保存规则后会重新扫描；不会取消已排队的传输，也不会删除原文件或已接收的副本。

## 扫描、断开和未备份文件

App 运行时会接收 macOS 文件变更通知，并定期重新检查。关闭主窗口仍能继续备份；退出 App 后停止，下次启动会补查。拔出硬盘或 SD 卡后保留文件清单和接收记录，重新连接后再检查。也可以在“更多”中手动重新扫描。

**未备份文件**页面显示失败原因，可以在访达中查看、重试，或忽略当前版本。忽略不会删除原文件；该文件之后发生变化，仍可能再次加入备份。

BackupDuck 不会修改或删除来源文件。**已接收**表示接收端已核对文件，不代表 Google 相册云端备份完成；请在接收端 Google 相册中开启对应文件夹备份，并确认上传结果。
