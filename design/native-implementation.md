| Apple 传输 | 核心类型 / 拍摄时间 / 大小 / 状态，单项详情；四个常用筛选与高级状态 | SQL 在分页前筛选，避免只过滤当前页；原生照片网格保留，缺失日期明确显示 |
| Apple 详情 | 阶段说明、长路径、来源、日期、错误与恢复入口 | 已接收但相册处理失败由 Pixel 处理；发送端不提供不起作用的“重试传输”按钮 |

| Android 传输 | 紧凑 RecyclerView、稳定 ID 与差异更新、类型 / 日期 / 状态、原生详情 | 缩略图缓存与取消、筛选与滚动锚点保留；详情重试只针对当前项 |

图库保持 UIKit / AppKit 原生网格；Android 长列表保持 RecyclerView。没有新增网页套壳、持续模糊或循环装饰动画。对历史功能的入口精简不等于删除功能。

## 防止后续设计漂移

- `tokens.json` 是颜色的唯一源；生成 Apple、Android 与浏览器变量，CI 检查生成结果。
- 共用卡片、品牌标记、状态徽标与传输详情集中在 Apple Shared；Android 主题与浏览器变量使用相同语义。
- 根目录 `AGENTS.md` 要求每次界面变更对照设计与动效规范；`iteration-checklist.md` 明确真机、小屏、失败恢复与辅助功能检查。
- 设计规则变化需要规范、变量 / 组件、参考图同时更新。自动检查不能替代视觉审阅和真机检查。

## 已完成的自动验证

- Rust 相关测试：71 通过，1 项既有测试按原条件忽略；单项重试范围、分页前筛选、全库搜索覆盖。
- Rust Clippy：相关四个 crate、全部目标、警告视为错误，通过。
- macOS、iOS 模拟器与 Android 应用均构建通过。
- 浏览器：实际管理页代码配合隔离测试 API，验证四页导航、浅深色、分页、全库查找和单项重试；无脚本异常。
- macOS：实际传输行与底部任务区在多个业务状态下量取高度，确认进度线不参加排版；浅深色实际组件渲染。
- Android：独立 validation 应用启动实际页面，隔离模拟器中的原生视图树导出浅深色图；传输项为合成数据。
- iOS：XCTest 导航主要页面、打开状态详情及展开任务说明；隔离模拟器的浅深色图使用正常的模拟器 Keychain 权限。

完整命令与截图入口见 `native-review/README.md`。每类图均说明数据来源与捕获方式。

## 仍需真机验收

- 真正的旧 Pixel 小屏（320 dp）、最大字体、持续 200 项滚动、连续接收下的帧率 / 温度、TalkBack。
- Apple 真窗口的系统侧边栏材质、增强对比 / 减少透明度 / 减少动态效果、VoiceOver、大字体、横屏；离屏组件图不能验证系统材质。
- 用真实设备检查配对、网络断开、拔 SD 卡、温度保护、相册失败后重试与状态回报。此次仅改界面和必要的筛选 / 单项重试范围，不代表重新完成整个媒体兼容实验。
- Google 相册云端结果仍无法由本地已保存状态证明，需要用户在 Google 相册核对。
