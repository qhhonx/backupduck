# 备份鸭动效指南 · v1.1

动效用于解释因果和层级。默认不使用循环装饰动画、弹跳、渐变呼吸或持续旋转的品牌吉祥物。老 Pixel 的接收和图库处理性能优先。

## 时间与曲线

| 行为 | 时长 | 变化 | 曲线 |
| --- | --- | --- | --- |
| 按压 / 高亮 | 80–120 ms | 背景或不透明度 | ease-out |
| 开关 | 160 ms | 拇指位移 | (0.2, 0.8, 0.2, 1) |
| 状态文字替换 | 120 ms | 淡入，不改变容器几何 | ease-out |
| 背景遮罩进入 | 140 ms | 不透明度 0 → 1 | ease-out |
| 详情 / 配对进入 | 220 ms | 12 px 轻移 + 淡入 | (0.2, 0.8, 0.2, 1) |
| 弹层退出 | 160 ms | 淡出，最多 8 px 位移 | ease-in |
| 有依据的进度更新 | 320 ms | 进度值插值 | (0.2, 0.8, 0.2, 1) |
| 筛选 / 排序 | 即时 | 数据更新，不整列表移动 | 无 |

原生优先使用系统交互与组件动画，例如 iOS Sheet、macOS Popover、Android BottomSheet，遵守系统取消手势。上表用于自定义组件。原型演示了进入、开关和进度，退出及文字淡入的完整转场仍由原生落地实现；不要把原型瞬间重绘误当最终动画标准。

## 稳定的任务状态区

桌面状态区基础高度 68，手机传输页 52，标题与解释始终有内容；大字体时一次性适配更高布局，不裁切。进度线是容器底边上的 2 px 叠层，不参加垂直排版。有进度显示真实百分比，没有进度不画线。不存在一个“预留空进度块”。

| 状态 | 主行 | 辅助行 | 进度线 |
| --- | --- | --- | --- |
| 传输中 | 正在传输到 Pixel XL | 项目数与当前速度 | 已知进度 |
| 手动暂停 | 传输已暂停 | 点继续恢复，已接收原件保留 | 保留当前值，颜色中性 |
| 高温暂停 | Pixel 正在降温 | 电池温度与业务恢复条件 | 停在当前值 |
| 处理失败 | 2 个文件未保存到相册 | 原件保留，可重试处理 | 不模拟前进 |
| 完成 | 本批文件已保存到 Pixel 相册 | 批次数；云端请到 Google 相册确认 | 消除线条 |
| 等待连接 | 等待 Pixel XL 重新连接 | 连接恢复后继续传输 | 无 |
| 无任务 | 等待连接接收设备 | 配对后即可开始备份 | 无 |

状态文字变化时用短淡入，不推挤相邻区域。警告图标替换同一位置的任务图标，警告文案替换辅助行；较长原因在任务页持续展示，不在固定区插入第三行。重要提示不能为了稳定布局被隐藏。

## 列表刷新与性能

- 以稳定文件 / 任务 ID 更新单行，不能按索引复用错误缩略图。
- 每行缩略图槽位固定。图片加载只替换槽内内容，不触发行高变化。
- 保留滚动位置、展开文件夹、筛选与选择。浏览器旧页不自动切回第一页。
- 接收计数、温度读数由业务通知更新；温度采样不是一次动画，不对每个小数变化做计数滚动。
- 完成 / 失败状态仅在确认结果后更新。用户点重试显示请求已提交，不能播放完成动效。
- 首屏静态骨架，不做无限闪烁。载入超过等待预算时显示文字状态与重试入口。
- Android 和浏览器使用实色弹层与无模糊遮罩。Apple 原生弹层使用系统材质；不对模糊半径做逐帧动画，不在内容卡片叠加材质。

## 减少动态效果与辅助技术

遵循 iOS / macOS Reduce Motion、Android Remove Animations、网页 `prefers-reduced-motion`。取消位移、弹性与进度插值；仍显示立即反馈和真实状态。焦点进入对话框，关闭后回到触发控件。状态朗读合并，避免每个进度百分比或每次刷新都打断用户。

## 材质与辅助功能

“减少透明度”与“减少动态效果”独立：前者将 Apple 导航与弹层恢复实色，后者取消位移与过渡；两者均不隐藏信息、不改变列表或任务区几何尺寸。旧系统与增强对比度同样使用清晰实色。鸭黄背板是静态品牌点缀，不闪烁、不呼吸、不旋转。

## 验收方式

在同一页面依次切换传输中 → 高温 → 处理失败 → 完成 → 离线，量取相邻列表区域和底部状态区边界；正常字体下几何尺寸不变，正文均有解释。确认关闭进度不会留下空白区，温度提示不会短时闪现又撑开高度。

连续浏览至少 200 个文件，检查滚动稳定、缩略图正确和分页保留；分别用 320 dp 小屏、最大系统字体、减少动态效果、深色模式验收。持续传输时观察旧 Pixel 帧率与温度，必要时取消所有非必要过渡。
