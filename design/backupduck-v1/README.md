# 备份鸭 · 跨平台视觉提案 v1.1

2026-10-02。独立的设计交付，未替换生产界面、未发布应用版本。

## 打开与体验

直接在浏览器打开 `index.html`，无需构建、联网或安装设计工具。也可以从仓库根目录启动本机静态预览服务，进入 `/design/backupduck-v1/`。

页顶切换 macOS、iOS、Android 和浏览器；右上切换深浅外观；“状态预览”切换正常、完成、首次使用、加载、未连接、处理失败、高温暂停和 SD 卡拔出。Android 支持 320 × 640 小屏。Apple 页面可比较“平台材质 / 旧系统实色”，以及“减少透明度”；这些是原型评审控制，不是产品设置。

- 点击应用里的导航切换页面。
- 点击文件打开详情、时间线与失败处理说明。
- 在系统图库“选择”照片，预览备份所选和强制重传确认。
- 在文件夹“查看文件”，切换平铺 / 文件夹树、时间 / 名称排序；“备份规则”分别说明白名单与黑名单。
- 点击接收端“连接新设备”，预览自动启动接收、显示码和扫描码流程。
- 浏览器传输记录支持筛选、搜索、每页 20 / 50 / 100、页码、首尾页和直接跳页。
- “动效指南”可演示状态区、进度线、弹层、开关的变化；尊重系统减少动态效果。

配对码、登录、文件、统计和设置都是示例，不会访问照片、启动接收、申请相机权限、上传、删除或修改真实配置。图片复用官网的生成风景样例，鸭子复用现有品牌图标。原型不接入任何第三方服务。

## v1.1 修订

- Apple 导航与标准弹层使用克制的材质示意，正文与进度保持实色；旧系统与辅助功能有实色回退。
- Android 使用 Material 风格控件与实色表面，保留小屏列表密度；浏览器继续以表格为中心。
- 首次连接与空状态补充鸭黄插画背板，规范页展示实际用法与状态色的区别。
- 保留深色模式；颜色样本数值跟随当前主题。

## 方案范围与边界

这一版选择“暖白 + 品牌蓝 + 少量鸭黄”的统一方向。使用原生平台的信息架构，不把四端套进同一张网页。浏览器稿通过表格、页码与详情组织信息，不新增照片下载或云端控制能力。

原型覆盖主要页面和典型状态，其他系统弹窗（权限、文件夹选择器、相机、系统分享、安装器）沿用各平台系统界面，不另画假系统控件。桌面窗口为评审尺寸，小屏手机单独校验；最终原生实现还需要 Dynamic Type、屏幕阅读器、键盘与真实设备验收。

生产落地前应确认视觉方向与核心交互。远端温度 / 空间等信息若当前发送端没有可用数据，显示“未提供”或带时间的“最近读数”；不得为了匹配视觉稿推测数值。照片拍摄时间与文件修改时间不得混用。未确认的 Google 云端状态不得新增成功标记。

任务在 Linear 的既有视觉改进记录上扩展，状态保持进行中，等待设计评审。仓库不保存私人任务链接、群聊截图、账号或用户照片。
