浏览器管理帮助

连接与访问

Pixel 和浏览器所在设备需要处于可互通的局域网。VPN 需要允许本地网络访问。在 Pixel → 备份鸭 → 设置 → 浏览器管理查看地址和 10 位访问码。

理解保存状态

已接收表示原件已收到并校验；已保存到相册表示 Pixel 系统相册处理完成。两者都不代表 Google 相册云端备份成功。云端状态请在 Google 相册中确认。

空间与原件

网页显示手机空间、备份鸭原件和最低可用空间；不会删除或导出原件。保留策略、历史原件清理和导出：Pixel → 备份鸭 → 存储。

恢复与排查

相册处理失败时原件仍保留。传输记录 → 点击文件名 → 重试此文件。重试请求不代表处理成功，请等待接收端更新结果。诊断导出：Pixel → 备份鸭 → 设置 → 诊断；应用更新：Pixel → 备份鸭 → 设置 → 应用更新。

安全与会话

仅在可信任的局域网使用本地管理页。关闭浏览器管理、撤销记住的浏览器或更换访问码后，可能需要重新登录。不要将地址、访问码和诊断中的私人信息公开分享。
