# Android v1.2 验证记录

2026-10-03。草案与原生试点均未提交、未发布。用户设计验收仍未完成。

## 原型

本地 Playwright 检查覆盖 63 个登记界面、182 个适用状态；所有登记的来源文件存在，页面目标有效。浏览器管理验证了错误输入阻止提交、保存成功、保存失败留在表单；原型未向外部服务发请求。

320 / 360 / 411dp，字体 1 / 1.3 / 2 倍检查导航图标与标签不相交、触控高度不小于 48dp。浅深色截图位于 `build/design-review/android-v1.2/`，均为模拟数据。测试脚本：`tests/android_design_prototype.cjs`。这不是所有字段的最大字体验收，也不是原生导航证据。

## 原生试点范围

- 浏览器管理独立次级页面。
- 查看真实管理地址与码、复制地址；正式应用保留 `FLAG_SECURE`，独立验收包默认遮蔽码并允许截图。
- 新码输入、字段错误、提交禁重、失败留在表单、重试与成功反馈。
- 重置码 / 撤销登录统一确认组件，失败仍在当前确认框可重试。
- Snackbar 与持续错误组件、固定提交区的统一底部弹层。
- 导航高度与图文间距、info 图标的路径修正。

其余二三级原生页面未按 v1.2 全部迁移。此前安装的完整主页面检查不能代替本轮试点验收。

## 证据边界

原生组件交互检查在隔离模拟器中注入成功 / 失败响应，验证输入、错误、禁重和返回；真实访问码业务另用现有 `dashboard_ui` 模式检查。注入测试不能证明真实网络访问。

此前带 `FLAG_SECURE` 的敏感弹层证据使用隔离测试 View 树绘制合成内容。此次独立验收包支持遮蔽码的真实窗口截图，主动显示码时重新启用安全标记，隐藏后恢复截图；正式应用不放开。旧 View 树图仍不证明硬件阴影、键盘或屏幕裁切。不得将真实访问码或二维码放进 repo。

真机最大字体、TalkBack、键盘遮挡、连续接收、实际浏览器登录撤销、后台恢复仍待检查；没有测试结果前不标为通过。

## 用户反馈修正：字重、启动状态和截图阻塞

- 真机诊断确认：正式应用与独立验收包都监听 8484，验收包持续记录 `receiver_start_port_in_use`。旧页面只判断 ready / 非 ready，没有异步错误反馈。独立包改用 48484，正式版端口保持 8484；更新后两端口均可连接，独立包的启动记录不再出现新的端口失败。
- 浏览器页和访问弹层复用 `BrowserStartupUI`，点击立即显示启动中；失败原因和重试持续保留，后台自动重试不让错误闪烁；点击重试立即唤醒服务重试，不必等待原 5 秒周期。接收就绪后还需实际确认浏览器服务启动。
- 页眉与设置标题使用明确粗体，说明使用带背景的统一 notice；补齐页眉分隔线。禁用 Material 自动高程叠色，避免弹层内卡片和次级按钮自行变蓝。
- 验收包访问码默认遮蔽，显示码时恢复 FLAG_SECURE；新码输入使用每位始终遮蔽的密码转换器，避免最后一位短暂明文。正式应用的敏感弹层继续禁止截图。
- 本地 Pixel 截图工具区分手机熄屏与受保护页面，保留 ⌘⇧7 与预览标注流程；不自动唤醒、解锁或改变锁屏设置。
- 新增原生检查已通过 411dp / 正常字体 / 浅色、320dp / 2 倍字体 / 深色：启动点击、异步失败、自动重试保留错误、手动重试、实际浏览器确认、遮蔽窗口截图及显示 / 隐藏保护切换。敏感内容的公开检查仍只使用合成响应。
- 首次检查在安全弹层关闭后立即截另一页面时，系统截图返回空；补充等待系统安全图层完成切换后的有限重试，随后通过。遮蔽访问弹层的实际窗口截图已成功。
- 新增实际窗口像素检查已确认浅深色弹层卡片匹配 `duck_surface`，没有蓝色叠色。遮蔽访问弹层截图属于真实屏幕截图；启动过程 / 失败截图属于共享组件的隔离场景，不冒充真机网络失败。
- Pixel 已更新独立验收包。真机当时熄屏，最后的视觉截图等待用户解锁；随后 Mac 也锁屏。未绕过锁屏、未设置持续唤醒。未提交、未推送、未发布应用版本。测试模拟器已关闭以释放资源。

## 用户反馈修正：弹层结构、间距与说明遗漏

上一轮通过的是组件行为、字重与截图能力，未覆盖本轮指出的复制按钮顺序、标签位置和说明卡片完整性；不能把那些通过记录视为视觉验收通过。

- 直接对照原型 CSS 与 DOM 顺序，访问页复制按钮放在地址卡片下方、说明卡片上方；去掉固定在底部的复制区。验收辅助动作收进访问码行，去掉大块验收提示。
- 表单外置固定标签，不使用系统浮动 hint；完整描边“重置为随机访问码”按钮，补齐设置说明。重置 / 退出浏览器确认补齐各自说明卡片和分隔提交区。
- 补充明确间距契约，单个相邻间距不叠加。弹层按内容测量，达到最大可用高度才滚动。重置确认不叠在表单上；取消返回保留输入，成功关闭旧表单。
- 独立验收应用和测试包编译、Android 单元测试通过。411dp / 标准字体 / 浅色、320dp / 2 倍字体 / 深色：顺序、卡片到复制按钮 20dp、复制到说明 16dp、标签到输入框 8dp、描边重置、三处说明、底部按钮完整显示、取消保留草稿、保存和确认失败重试、启动状态及密码保护通过。
- 四个弹窗的实际原生窗口截图已人工查看，对照记录在 `native-review.html`；截图使用隔离模拟器的合成数据，并非真实 Pixel 窗口。大字体正文需要滚动，固定提交按钮不裁切。
- 真实 JNI 接口检查通过：保存 10 位码、退出登录不改码、随机重置；检查结束还原模拟器原测试码。没有在真实 Pixel 上重置访问码或退出浏览器。

## 用户反馈修正：复制提示与 info 图标错位

- 复制原先向底下 Activity 添加 Snackbar，访问弹层未关闭时遮挡了反馈。改为向当前弹层窗口添加统一短提示，复制的合成地址与提示的实际可见范围同时检查。

- 人工检查浅深色实际窗口图，确认复制反馈显示在访问弹层上，图标与中文首行对齐；大字体正文需滚动。没有把模拟器结果当作旧 Pixel 字体、键盘或 TalkBack 的真机通过记录。
